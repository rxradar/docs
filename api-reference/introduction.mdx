## Base URL

```
https://api.rxradar.xyz
```

## Authentication

All requests require an API key in the `Authorization` header:

```bash
Authorization: Bearer rx_YOUR_API_KEY
```

## Response format

All responses are JSON.

### Paginated response

```json
{
  "data": [...],
  "total": 1234,
  "page": 1,
  "per_page": 50,
  "pages": 25
}
```

### Error response

```json
{
  "detail": "Error description"
}
```

## HTTP status codes

| Code | Meaning |
|------|---------|
| 200 | Success |
| 400 | Bad request |
| 401 | Unauthenticated |
| 403 | Forbidden |
| 404 | Not found |
| 429 | Rate limit exceeded |
| 500 | Server error |
