---
title: "List Network Stores"
api: "GET /v1/networks/{slug}/stores"
description: "List all stores (pharmacies) in a network"
---

<ParamField path="slug" type="string" required>
  Network slug (e.g. "cvs")
</ParamField>

<ParamField query="page" type="integer" default="1">
  Page number
</ParamField>

<ParamField query="per_page" type="integer" default="50">
  Results per page (max: 100)
</ParamField>

<RequestExample>
```bash cURL
curl -X GET "https://api.rxradar.xyz/v1/networks/cvs/stores?per_page=10" \
  -H "Authorization: Bearer rx_YOUR_API_KEY"
```
</RequestExample>

</ResponseExample>
