  Page number
</ParamField>

<ParamField query="per_page" type="integer" default="50">

</ParamField>

<RequestExample>
```bash cURL
curl -X GET "https://api.rxradar.xyz/v1/networks?per_page=10" \
  -H "Authorization: Bearer rx_YOUR_API_KEY"
```

```python Python
import requests

response = requests.get(
    "https://api.rxradar.xyz/v1/networks",
    headers={"Authorization": "Bearer rx_YOUR_API_KEY"},
    params={"per_page": 10}
)

networks = response.json()
```
