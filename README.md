# RxRadar Docs

Source for [docs.rxradar.xyz](https://docs.rxradar.xyz) — the API reference for [RxRadar](https://rxradar.xyz), the pharmacy shelf index. RxRadar indexes retail pharmacy chains SKU by SKU — prices, promotions, stock, shelf positions and ratings — served through dashboards and an API.

## Development

Install the [Mintlify](https://mintlify.com) CLI and run the docs locally:

```bash
npm i -g mint
mint dev
```

The preview runs at http://localhost:3000.
